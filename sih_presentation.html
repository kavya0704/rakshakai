⚠
Key Challenges & Engineered Mitigations
Operational Challenge / Risk Rakshak AI Mitigation Strategy
Himalayan Cold & Blizzards: Extreme weather causing false sensor triggers. Dynamic Weather Discounting: Environmental factors auto-adjust sensor weights in real-time risk equations.
Intermittent Border Comms: Remote radio/satellite link dropouts. Local Event Queueing: Buffers events locally; synchronizes automatically on reconnection with offline summaries.
Single-Sensor False Alarms: Wildlife or debris triggering false alarms. Multi-Source Verification: Incident creation strictly requires ≥2 independent source types within time window.
Tactical Data Privacy: Risk of data exposure on cloud LLMs. Data Sanitization: Only tokenized, anonymized metadata (zero soldier PII/coordinates) sent to LLM; local models ready.
